# LevelUP

## Goal

LevelUP is a mobile-first personal RPG habit app.

Primary development goal: learn coding while building the app incrementally.

Keep the code easy to understand and maintain.

## Stack

* Next.js App Router
* TypeScript
* Tailwind CSS
* Supabase PostgreSQL
* Motion for React

Supabase and Motion are planned dependencies. Do not install or implement them until requested.

## Development Rules

* Implement only what the current prompt requests.
* Do not build future features proactively.
* Do not over-engineer.
* Do not add dependencies unless necessary.
* Prefer simple solutions over clever abstractions.
* Use TypeScript for new code.
* Use Tailwind for styling.
* Build mobile-first.
* Create reusable components when they clearly reduce duplication.
* Preserve existing working features.
* Do not refactor unrelated code.

## Learning

Code should be understandable for someone learning React and Next.js.

Prefer clear:

* component structure
* variable names
* function names
* business logic

Avoid unnecessary architecture or abstraction.

## Before Editing

Inspect relevant existing files before making changes.

## After Editing

* Check TypeScript/errors.
* Run `npm run build`.
* Fix errors caused by the changes.
* Do not perform unrelated refactors.

Keep the final response concise:

* what changed
* important files changed
* build/test result
